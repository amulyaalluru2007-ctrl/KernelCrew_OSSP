fork()	Creates a new child process
exec()	Executes the Linux command in the child process
wait()	Makes the parent wait until the child finishes
getpid()	Returns the current process ID
getppid()	Returns the parent process ID
read()	Reads the command entered by the user


uname	  Displays operating system and kernel information
lscpu	  Displays CPU architecture and processor information
lsblk	  Displays storage devices and block devices
ps	    Displays information about running processes
top    	Displays real-time process and system resource usage
